# Эмулятор оболочки ОС (вариант 18)

Практическая работа по дисциплине «Конфигурационное управление», РТУ МИРЭА.
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI).

Язык реализации — Python 3.9+, интерфейс — Tkinter (входит в стандартную
поставку Python), сторонние зависимости не нужны.

## Этап 1. REPL

Минимальный прототип: окно с полем вывода и строкой ввода команд.
Команды `ls` и `cd` пока являются заглушками и выводят своё имя и аргументы.

### Возможности

- **GUI**: окно Tkinter, заголовок окна содержит имя VFS
  (`Эмулятор оболочки — vfs`), приглашение к вводу — `vfs$`.
- **Парсер** (`src/shell_parser.py`):
  - слова разделяются пробелами;
  - раскрываются переменные окружения реальной ОС: `$HOME`, `${USERNAME}`;
  - неизвестная переменная заменяется пустой строкой, как в sh;
  - в двойных кавычках `"..."` переменные раскрываются, пробелы сохраняются;
  - в одинарных кавычках `'...'` текст берётся буквально;
  - соседние фрагменты склеиваются: `a"b c"'d'` → `ab cd`;
  - незакрытая кавычка — ошибка разбора.
- **Команды** (`src/commands.py`):

  | Команда | Описание | Ошибки |
  |---|---|---|
  | `ls [-l\|-a\|-la\|-al] [путь...]` | заглушка, выводит имя и аргументы | неизвестная опция |
  | `cd [путь]` | заглушка, выводит имя и аргументы | больше одного аргумента |
  | `exit [код]` | закрывает эмулятор | нечисловой код, больше одного аргумента |

- **Обработка ошибок**: неизвестная команда, неверные аргументы, ошибка
  разбора строки. Ошибки выводятся красным цветом.
- **История команд**: стрелки ↑ / ↓ в строке ввода.

### Структура

```
src/
  main.py          — GUI (окно, ввод/вывод)
  commands.py      — реализация команд и функция execute()
  shell_parser.py  — разбор строки и раскрытие переменных окружения
tests/
  test_parser.py   — тесты парсера
  test_commands.py — тесты команд
run.bat, run.sh    — запуск эмулятора
test.bat           — запуск тестов (Windows)
```

## Запуск

Windows:

```
run.bat
```

Linux/macOS:

```
./run.sh
```

## Тесты

```
python -m unittest discover -s tests -v
```

## Пример сеанса

Переменные окружения взяты из реальной ОС (Windows):

```
vfs$ ls
ls: аргументы []
vfs$ ls -l $HOME
ls: аргументы ['-l', 'C:\Users\Василий']
vfs$ cd "$HOME/My Docs"
cd: аргументы ['C:\Users\Василий/My Docs']
vfs$ cd '$HOME'
cd: аргументы ['$HOME']
vfs$ ls ${USERNAME}_dir $NOPE end
ls: аргументы ['Василий_dir', 'end']
vfs$ cd a b
cd: слишком много аргументов
vfs$ ls -z
ls: неверная опция '-z'
vfs$ foo bar
foo: команда не найдена
vfs$ ls "unclosed
ошибка разбора: незакрытая кавычка "
vfs$ exit abc
exit: требуется числовой аргумент: abc
vfs$ exit
```
